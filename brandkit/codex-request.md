# 요청: JISOAR 로고 방향 독립 판단 (동의하지 말고 근거로 반박 가능)

## 배경
- JISOAR(지소어) = 한국 1인 개발 사업자. 고객: 웹서비스·앱·업무 시스템을 맡길 소상공인/중소기업 대표. 사이트 jisoar.com 리뉴얼 중.
- 색 확정: Night #101A33(글자), Dawn Paper #F7F5F0(바탕), Sky #3366E8(주색), Sunrise #F2A541(강조 한 점만), Haze #E6ECF7.
- 이름 의미: SOAR(날아오름). 사이트 첫 화면에 하늘 영상.

## 지금까지 시안
심볼 3개(Recraft 생성): (1) J 아래가 위로 쓸려 올라가고 끝에 주황 점 — J가 사선에 그어진 듯 어색 (2) 남색 막대 3개 위에 파란 막대 하나가 15도 들림 — 아래 3개 길이 같아 햄버거 메뉴처럼 보임 (3) 파란 둥근 사각 안에 날개(사선 3줄) 흰색 음각 — 서류/줄무늬처럼 보임.
워드마크 3개(구글 폰트+디테일 1개): W1 Sora Bold "JISOAR", O 자리에 수평선 위 반원 해(주황) / W2 Manrope ExtraBold, A 가로획 제거 + 꼭대기 위 주황 점 / W3 Outfit 소문자 "jisoar", i 점을 주황 해로.

## 사용자 질문
"요즘 트렌드는 JISOAR 글자 자체를 형상화하는 타이포그래피 로고 아닌가?" 사용자는 무조건 동의하지 말고 세계·국내 감각적인 사례를 근거로 정확히 답하라고 함.

## 묻는 것
1. 이 사업 규모·고객에 워드마크 주도(+파생 아이콘) vs 심볼 주도 중 무엇이 맞는가, 근거와 반례.
2. 위 워드마크 3안 각각의 약점(특히 수평선 위 해, 점 하나 얹기 같은 클리셰 여부, 6글자 JISOAR 대문자 가독성, J·I 붙는 간격).
3. 더 나은 구체 방향 1~2개(글자 구조로 SOAR를 표현하는 방식 등), 참고할 실존 사례(해외·국내)를 명시.
