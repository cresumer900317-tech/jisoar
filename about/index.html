뜻이 있는 것은,
날아오릅니다

jisoar(지소어)는 뜻 지(志)와 soar(날아오르다)를 합친 이름입니다. 품은 아이디어를 실재하는 서비스로 띄워 올리는 것. 이 스튜디오가 하는 일의 전부입니다.

Philosophy

직접 만들고, 직접
운영해 본 사람이
만듭니다

커뮤니티 플랫폼을 직접 운영하고, iOS · Android 스토어 심사를 직접 통과하고, 실제 운영 중인 시스템을 직접 다뤄 본 경험 위에서 납품하고 끝나는 개발이 아니라 운영까지 견디는 서비스를 만듭니다.

(01)

실전주의

포트폴리오용 목업을 만들지 않습니다. 실제 사용자가 쓰고, 실제 현장에서 돌아가는 것만 만듭니다.

(02)

처음부터 끝까지

기획 · 디자인 · 개발 · 배포 · 운영. 단계마다 담당자가 바뀌지 않으니 말이 통하고, 속도가 다릅니다.

(03)

정직한 범위

할 수 있는 것과 없는 것을 처음부터 말합니다. 견적은 단계별로, 필요한 만큼부터 시작합니다.

History

걸어온 길

2025년 커뮤니티 플랫폼에서 시작해 iOS · Android 앱 출시, 결혼식 현장, 기업 시스템까지. 실제로 쓰인 것만 남긴 기록입니다.

2025Friends

게임 커뮤니티 플랫폼 오픈

게임 커뮤니티 플랫폼을 직접 설계하고 오픈. 가입 퍼널부터 콘텐츠 운영까지 서비스 운영의 전 과정을 실전으로 시작했습니다.

2026Guild Lounge

모바일게임 길드 관리 앱 iOS · Android 출시

길드 일정·랭킹·커뮤니티 네이티브 앱을 App Store와 Google Play에 정식 출시. 심사부터 배포·업데이트 운영까지 전 과정을 직접 진행했습니다.

2026. 06Wedding Memory Cloud

결혼식 하객 사진 공유 서비스 실전 검증

하객이 QR로 사진·영상을 올리는 결혼식 갤러리 서비스를 실제 결혼식 현장에서 운영하며 검증을 마쳤습니다.

2026기업 프로젝트

기업용 랭킹 조회·관리 대시보드 리뉴얼 수주

랭킹 조회·관리 대시보드 시스템 리뉴얼 프로젝트를 수주. 다단계 권한 설계와 데이터 관리 시스템을 구축하고 있습니다.
