HOW WE WORK

범위를 정하고,
결과를 보며 진행합니다

필요한 기능부터 단계별로. 제작 중에도 실제 링크로 중간 결과를 확인합니다.

  1. 01 / 상담

    문제부터 이해합니다

    목적, 사용자, 일정과 예산을 이야기합니다.

  2. 02 / 제안

    범위를 명확하게

    필요한 기능과 제작 범위, 견적을 문서로 정리합니다.

  3. 03 / 제작

    보면서 함께 조정

    중간 결과를 공유하고 피드백을 반영합니다.

  4. 04 / 출시

    운영까지 연결

    배포를 마무리하고 유지보수 방식을 함께 정합니다.
