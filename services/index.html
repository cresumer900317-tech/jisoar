홈페이지 한 장부터,
설비 모니터링까지

네 가지 영역에서 일합니다. 공통점은 하나 — 직접 만들고 운영해 본 것만 서비스로 제공한다는 것.

01 / Web

웹사이트 · 홈페이지 제작

회사 소개 홈페이지, 제품 랜딩 페이지, 회원제 커뮤니티 플랫폼까지. 예쁘기만 한 페이지가 아니라 검색에 잡히고, 모바일에서 완벽하고, 링크 공유 시 카드가 제대로 뜨는 — 완성된 상태로 인도합니다.

  • 브랜드 홈페이지 — 기업·개인사업자 소개 사이트
  • 랜딩 페이지 — 제품·이벤트 단일 페이지
  • 커뮤니티 플랫폼 — 회원가입 · 게시판 · 랭킹 시스템
  • 반응형 · SEO · OG 미리보기 · 도메인 연결 포함
  • 유지보수 및 콘텐츠 업데이트 지원
02 / Mobile App

모바일 앱 개발

React Native 기반 크로스플랫폼으로 iOS · Android를 한 번에 개발합니다. 앱은 만드는 것보다 스토어에 올리는 게 진짜 일입니다 — 심사 리젝 대응부터 정식 출시, 업데이트 배포까지 직접 겪어 본 프로세스로 진행합니다.

  • iOS + Android 동시 개발 — 하나의 코드베이스
  • App Store · Google Play 출시 대행 — 심사 대응 포함
  • 푸시 알림 · 로그인 · 커뮤니티 기능
  • 기존 웹 서비스의 앱 전환
  • 출시 후 업데이트 · 운영 지원
03 / Dashboard · System

관리자 대시보드 · 업무 시스템

엑셀과 수작업으로 돌아가던 업무를 시스템으로 바꿉니다. 데이터 조회 · 검색 · 관리 화면, 역할별 권한 분리, 자동 리포트까지 — 쓰는 사람의 동선에 맞춰 설계합니다.

  • 데이터 조회 · 관리 대시보드 — 검색 · 필터 · 정렬
  • 다단계 권한 시스템 — 관리자 · 운영자 · 조회 전용 등
  • 기존 데이터(엑셀 · DB) 이관 및 정리
  • 자동 집계 · 리포트 · 그래프
  • 사내 업무 도구 · 인트라넷
04 / Industrial IoT

산업 IoT · 설비 모니터링

물류 · 제조 현장의 설비 데이터를 수집해 실시간으로 보여줍니다. PLC 통신부터 데이터 파이프라인, 모니터링 대시보드까지 — 현장을 아는 엔지니어가 직접 설계합니다.

  • PLC 데이터 수집 — Mitsubishi MC Protocol 등 산업 프로토콜
  • 데이터 파이프라인 — Node-RED 기반 수집 · 가공
  • 실시간 모니터링 대시보드 — ThingsBoard · 커스텀 웹
  • 설비 상태 알림 · 이력 조회
  • 현장 네트워크 · 통신 구성 자문
02 Process

진행은 이렇게

상담

필요한 것과 예산을 편하게 이야기합니다. 이 단계는 무료입니다.

제안 · 견적

범위를 문서로 정리하고 단계별 견적을 드립니다. 한 번에 크게가 아니라, 필요한 만큼부터 시작합니다.

개발

중간 결과물을 실제 링크로 공유하며 진행합니다. 완성되기 전에도 계속 눈으로 확인할 수 있습니다.

배포 · 운영

도메인 연결, 스토어 출시, 서버 셋업까지 마무리하고 이후 유지보수도 함께합니다.
