하는 일

업무 시스템 · 대시보드가장 많이 맡는 일

엑셀과 수작업으로 돌아가던 업무를 실제로 일하는 사람의 순서에 맞춘 화면으로 바꿉니다. 데이터 조회·검색, 권한 분리, 자동 집계와 리포트까지 필요한 만큼 만듭니다.

  • 데이터 조회·관리 화면: 검색, 필터, 정렬, 엑셀 일괄 등록
  • 권한이 나뉜 시스템: 관리자·운영자·고객 전용 화면
  • 예약·신청·조회·랭킹·계산기 같은 기능형 웹서비스
  • 기존 엑셀·DB 데이터 이관, 자동 수집과 집계
  • 사내 업무 도구, 인트라넷
관련 작업: RANKLAB, 정산 이체 파일 도구

모바일 앱

React Native로 iOS·Android를 한 번에 개발합니다. 스토어 심사 대응부터 출시, 출시 뒤 업데이트까지 직접 진행합니다.

  • iOS·Android 동시 개발 (하나의 코드베이스)
  • App Store·Google Play 등록과 심사 대응
  • 푸시 알림, 로그인, 커뮤니티 기능
  • 운영 중인 웹서비스의 앱 전환
  • 출시 후 업데이트와 운영
관련 작업: Guild Lounge

웹사이트 · 홈페이지

회사 소개 홈페이지, 제품 랜딩 페이지, 회원제 커뮤니티를 만듭니다. 모바일에서 편하게 읽히고, 검색과 링크 미리보기까지 챙깁니다.

  • 기업·개인사업자 소개 사이트
  • 제품·이벤트 랜딩 페이지
  • 회원가입·게시판·랭킹이 있는 커뮤니티
  • 반응형, SEO, 링크 미리보기, 도메인 연결
  • 유지보수와 콘텐츠 업데이트
관련 작업: Friends, Wedding Memory Cloud

진행 방식

필요한 기능부터 단계별로 진행합니다.

  1. 상담

    무엇을 바꾸고 싶은지, 누가 쓰는지, 일정과 예산을 듣습니다. 상담은 무료입니다.

  2. 범위와 견적

    만들 기능과 제외할 것을 문서로 정리하고 단계별 견적을 드립니다.

  3. 개발

    중간 결과를 실제 링크로 공유하고, 써 보면서 조정합니다.

  4. 출시와 운영

    도메인·서버·스토어 배포를 마무리하고 유지보수 방식을 정합니다.
