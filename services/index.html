하는 일

업무 시스템 · 대시보드주력 분야

엑셀과 수작업으로 하던 업무를, 사용자의 업무 순서에 맞춘 시스템으로 바꿉니다. 조회와 검색, 권한 분리, 자동 집계와 리포트까지 필요한 만큼 만듭니다.

  • 데이터 조회·관리 화면: 검색, 필터, 정렬, 엑셀 일괄 등록
  • 사용자별 접근 권한을 구분한 시스템: 관리자, 담당자, 고객 전용 화면
  • 예약, 신청, 조회, 계산기 같은 기능형 웹 서비스
  • 기존 엑셀 파일과 데이터베이스의 데이터 이관, 자동 수집과 집계
  • 사내 업무 도구
관련 작업: RANKLAB, 정산 이체 파일 도구

모바일 앱

React Native로 iOS와 Android 앱을 함께 개발합니다. 스토어 심사 대응부터 출시와 이후 업데이트까지 직접 진행합니다.

  • 공통 코드 기반의 iOS·Android 앱 개발
  • App Store·Google Play 등록과 심사 대응
  • 푸시 알림, 로그인, 게시판 기능
  • 운영 중인 웹 서비스의 앱 전환
  • 출시 후 업데이트와 운영
관련 작업: 길드라운지

웹사이트 · 홈페이지

회사 소개 홈페이지, 제품 랜딩 페이지, 회원제 커뮤니티를 만듭니다. 휴대폰에서도 읽기 편하게 만들고, 검색 노출을 위한 기본 설정과 링크 미리보기까지 적용합니다.

  • 회사·개인사업자 소개 사이트
  • 제품·이벤트 랜딩 페이지
  • 회원가입, 게시판, 랭킹이 있는 커뮤니티
  • 반응형, 검색 노출 설정, 링크 미리보기, 도메인 연결
  • 유지보수와 콘텐츠 업데이트
관련 작업: 메이플키우기 라운지, Wedding Memory Cloud

기본 비용

작게 시작해서 필요한 기능을 더하는 방식으로 비용을 낮춥니다.

  • 홈페이지 · 랜딩 페이지

    5페이지 이내 소개 사이트. 휴대폰 화면, 도메인 연결, 검색 등록까지

    30만원부터약 1주

  • 업무 자동화 도구

    엑셀 변환, 계산기, 신청 접수처럼 반복 작업 하나를 줄이는 도구

    50만원부터1~2주

  • 업무 시스템 · 대시보드

    화면 5~8개 규모. 로그인과 권한, 데이터 관리 화면, 집계 대시보드

    100만원부터3~5주

  • 모바일 앱

    화면 10개 안팎의 기본 앱. iOS·Android 개발, 스토어 등록과 심사 대응

    200만원부터4~8주

부가세 별도입니다. 시작가는 위에 적은 기본 구성 기준이고, 기능 범위를 정한 뒤 확정 견적을 드립니다. 착수 시 50%, 납품 후 50%를 받습니다. 기간은 필요한 자료를 받은 날부터이며, 앱 스토어 심사 기간은 포함하지 않습니다. 서버, 도메인, 앱 스토어 등록비 같은 외부 비용은 실비로 따로 듭니다.

포함

  • 서버, 도메인, 보안 인증서 관리와 상태 확인
  • 서비스가 멈추거나 기존 기능에 오류가 생기면 원인 확인과 복구 (월 합계 3시간 이내)
  • 작은 수정 월 2건: 문구·이미지 교체, 간단한 화면 수정 (건당 1시간 이내)
  • 데이터 백업 확인
  • 평일 기준 1~2일 안에 첫 답변 (복구 완료 시점은 문제에 따라 다릅니다)

별도

  • 새 기능이나 화면 추가: 건별 견적
  • 월 작업 한도를 넘는 복구와 수정: 시작 전에 견적을 먼저 드립니다
  • 외부 서비스 정책이나 API 변경에 맞춘 개편 작업
  • 서버, 도메인, 유료 API, 앱 스토어 연회비 같은 외부 비용
  • 쓰지 않은 수정 건수는 다음 달로 넘어가지 않습니다
  • 데이터 자동 수집처럼 서버가 상시 작업하는 시스템과 앱 정기 업데이트는 작업량에 따라 따로 정합니다

진행 방식

필요한 기능부터 단계별로 진행합니다.

  1. 상담

    무엇을 바꾸고 싶은지, 누가 쓰는지, 일정과 예산을 듣습니다. 상담은 무료입니다.

  2. 범위와 견적

    만들 기능과 만들지 않을 기능을 문서로 정리하고 단계별 견적을 드립니다.

  3. 개발

    중간 결과를 테스트 링크로 공유합니다. 직접 사용해 보신 의견을 받아 함께 조정합니다.

  4. 출시와 유지보수

    도메인 연결, 서버 배포, 앱 스토어 등록을 마치고 유지보수 방식을 정합니다.
