업무 시스템

리워드 광고 관리

Toprise

담당 기획, 화면 설계, 개발, 순위 수집 서버 운영, 유지보수
구성 관리자 웹, 순위 수집 서버, 데이터베이스
상태 운영·유지보수 중

의뢰
기존에 쓰던 리워드 광고 관리 서비스를 새로 만들어 달라는 의뢰였습니다.키워드별 광고 슬롯의 순위와 진행 현황을 확인하고, 광고 기간과 정산을 한 시스템에서 관리하는 것이 목표였습니다.
만든 것
상품 링크를 넣으면 상품 정보를 자동으로 불러와 등록합니다.정해진 시간마다 검색 순위를 수집해 기록으로 남깁니다.총판·대행사·광고주 등급별 권한 관리, 엑셀 일괄 등록, 연장·수정 요청 처리, 정산 내역 관리, 일별 마감 기능을 갖췄습니다.
운영
정식 운영 중이며, 순위 수집 서버 관리와 유지보수를 함께 맡고 있습니다.
정산 업무 도구

Paylist

담당 기획, 개발, 배포, 유지보수
구성 브라우저에서만 동작하는 웹 도구
상태 고객사에 제공 중

도구 열기
의뢰
체험단 정산 목록을 은행 대량이체 양식으로 옮겨 적는 작업을 줄이고, 누락되거나 확인이 필요한 계좌 정보를 미리 찾고 싶다는 요청이었습니다.
만든 것
정산 엑셀 파일을 올리면 은행, 계좌번호, 예금주, 금액을 정리하고 빠진 값이나 확인이 필요한 행을 표시합니다.검토를 마치면 거래 은행의 대량이체 양식에 맞춘 파일을 만듭니다.
데이터 처리
정산 데이터는 서버로 보내지 않고 브라우저 안에서만 처리합니다.
주식·코인 자동매매

Ranklab

담당 기획, 개발, 서버 운영
구성 시세 수집과 매매 엔진, 대시보드 웹
상태 매일 자동 실행, 운영 중

만든 이유
감정에 흔들리지 않고 정해 둔 규칙대로 매매하는 시스템을 만들고, 어떤 판단이 실제로 성과를 내는지 기록으로 비교하고 싶었습니다.
만든 것
코인과 국내·미국 주식 시세를 모으고, Claude와 Codex가 각자 세운 계획과 규칙형 전략을 같은 기준으로 실행합니다.수수료와 세금을 계산해 계좌별 성과를 대시보드에 보여 줍니다.
운영
정해진 시간마다 자동으로 실행되며, 시세 연결 오류나 정산 문제를 직접 점검하고 고칩니다.
